# Double Pi 8×8 点阵贪吃蛇

烧录文件：`Obj/Template.hex`。工程：`Template.uvprojx`。

## 上板设置

先断电调整跳线和拨码开关，再上电。

| 母板标记 | 设置 | 用途 |
| --- | --- | --- |
| J7 | 短接 OE 与 GND（1–2） | 使能 74HC595 点阵驱动 |
| J4 | 短接 OE 与 VCC，禁用数码管 | 数码管与点阵共用数据线，本程序不使用数码管 |
| P00～P07 | 全部 ON | 点阵 8 根行线 |
| P34、P35、P36 | ON | 74HC595 数据、锁存、移位时钟 |
| P12、P16、P17 | ON | 三个游戏按键 |
| P11 | ON | 失败时的短蜂鸣提示 |
| P20～P27 | OFF | 本程序不使用流水灯 |
| P30、P31 | 串口烧录时 ON | CH340 串口下载 |

其他未使用的拨码开关可置 OFF。做本实验时，不接 LCD、OLED、步进电机等扩展模块，避免共用 IO 干扰。SW1 与板载触摸模块共用 P12，游戏时避免碰触摸区。

串口下载沿用原来的 J6 和 FlyMcu 设置。下载时 BOOT0=1、BOOT1=0；下载完成后 BOOT0 改回 0 再复位，才能断电后自动从 Flash 运行。

**不要按 SW2。** SW2 和点阵锁存信号共用 PA13，按下会把这根输出线接地。它没有参与游戏控制。

## 操作

- 上电后显示初始三格蛇，等待开始。
- **SW4：开始、暂停、继续；失败或胜利后按它重新开始。**
- **SW1：相对当前行进方向左转。**
- **SW3：相对当前行进方向右转。**
- 例如蛇向右走时，左转是向上，右转是向下。
- 按键按下触发一次，长按不连续转向。每走一格只接收一次转向，避免连续按键让蛇直接反向。
- 蛇常亮，食物闪烁。每约 300 毫秒移动一格，吃到食物增长一格。
- 四边互通：从右边出去会从同一行左边出现，上下边也一样；穿越后撞到自身仍会显示 X。铺满 64 格显示笑脸，暂停时蛇闪烁。
- 失败时只触发一次蜂鸣提示：PA1/P11 低电平有效。当前保留用户调整后的参数，持续约 3000 毫秒、100% 导通，会比之前的轻短提示明显得多。上电、开始、暂停和胜利不响，重新开始会取消尚未结束的提示。板载为有源蜂鸣器，降低导通时间不等于精确调节音量，实际响度需要上板确认。

## 硬件与代码

系统时钟沿用 8 MHz 外部晶振乘 9，内核时钟 72 MHz。

| 功能 | 母板网络 | STM32 引脚 |
| --- | --- | --- |
| 点阵 ROW1～ROW8 | P00～P07 | PB8～PB15 |
| 74HC595 SER | P34 | PA12 |
| 74HC595 RCLK | P35 | PA13 |
| 74HC595 SRCLK | P36 | PA14 |
| SW1 | P12 | PA2 |
| SW3 | P16 | PA6 |
| SW4 | P17 | PA7 |
| 蜂鸣器 | P11 | PA1 |

接线依据：用户提供的 Double Pi Rev3.0 手册，第 3.1、3.10、3.18、4.5、4.6 节。点阵为共阴型，PB8～PB15 驱动行阴极（低电平点亮），74HC595 驱动列阳极（高电平选通）。每约 1 毫秒扫描一列，切列前将所有行拉高熄屏，再锁存单列高电平，最后将需要点亮的行拉低；完整画面刷新率约 120 Hz。主循环处理按键和移动，不使用阻塞的 300 毫秒延时。

**PA13、PA14 被点阵占用，运行游戏时 SWD 和 JTAG 都关闭。** 串口 ISP 烧录不受影响；后续恢复调试接口可通过串口烧录其他程序。

- `User/main.c`：GPIO、74HC595 扫描、按键消抖和显示；顶部 `MOVE_INTERVAL_MS` 可调整移动间隔。
- `User/main.c` 顶部 `BUZZER_DURATION_MS` 调整提示长度，当前为 3000；`BUZZER_ON_US` 调整每毫秒的导通微秒数，允许 0～1000，当前为 1000，即 100%。若要恢复课堂轻短提示，可分别设为 40 和 100。蜂鸣器分时驱动沿用原来的 1 毫秒刷新等待，不会整段阻塞点阵。蜂鸣器 GPIO 使用开漏输出，高阻态静音，不占用定时器。
- 蜂鸣剩余时长使用 32 位计数器，可正确存储 3000 毫秒。0% 或 100% 导通时跳过长度为零的阶段，不调用 `delay_us(0)`；这份 SysTick 轮询延时函数的零重装值不会产生等待的计数完成标志，调用后会卡住主循环。
- `User/snake.c`、`User/snake.h`：不依赖硬件的蛇身、食物、碰撞和游戏状态逻辑。
- `tests/snake_test.c`：桌面运行的游戏逻辑测试，不编入单片机固件。
- `tests/matrix_test.c`、`tests/mocks/`：模拟 GPIO 和 74HC595，直接运行实际显示驱动，检查共阴极性、切列消隐、移位顺序、PB0～PB7 不被改变以及初始画面。覆盖全部 8 列、每列 256 种行图案；旧版极性错误会使该测试失败。

构建与验证：Keil ARM Compiler 5 完整重编译，0 错误、0 警告；桌面测试覆盖四条边全部 32 个出口的穿越、连续穿越、穿越后吃食物与撞自身、增长、转向、暂停、进入即将移走的尾格、只剩一个空格时的食物生成、胜利和重新开始。显示方向、亮度和实际按键接触效果仍需上板确认。
