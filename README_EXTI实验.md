# EXTI 按键、双向流水灯和蜂鸣器实验

当前固件对应课堂照片中的新实验。贪吃蛇版本保存在 Git 提交 `79ea6b1` 中。

## 操作

| 按键 | 引脚 | 稳定按下后的动作 |
| --- | --- | --- |
| SW1 | PA2 / P12 | 从 D4 开始，D4 → D5 → … → D11 → D4 循环 |
| SW2 | PA13 / P35 | 从 D11 开始，D11 → D10 → … → D4 → D11 循环 |
| SW3 | PA6 / P16 | 开启蜂鸣器，持续鸣叫 |
| SW4 | PA7 / P17 | 关闭蜂鸣器 |

上电时所有灯灭、蜂鸣器关闭。每个按键稳定约 20 毫秒后执行一次动作，长按不重复触发。流水灯每 200 毫秒切换一盏，方向切换会从对应端点重新开始。蜂鸣器开关不影响流水灯；同时确认 SW3、SW4 时，以关闭为准。

## 上板设置

先断电调整拨码和跳线，再上电。

- **ON：P20～P27、P11、P12、P35、P16、P17。**
- P30、P31 沿用串口下载需要的 ON 设置，J6 沿用原来的串口跳线。
- **J7 接 OE–VCC，禁用点阵；J4 接 OE–VCC，禁用数码管。**
- 不使用的 P00～P07、P34、P36 等开关可置 OFF；不接 LCD、OLED、步进电机等共用 IO 的扩展模块。
- 本实验 **SW2 可以按，也必须使用**；它现在是输入按键，不再是点阵锁存输出。
- SW1 与板载触摸模块共用 P12，按键实验时避免碰触摸区。
- LED D4～D11 对应 PB0～PB7，低电平亮；蜂鸣器对应 PA1/P11，低电平响。本实验按课件使用持续鸣叫，SW4 可关闭；把 P11 拨到 OFF 可物理静音。
- PA13 用作 SW2，PB3/PB4 用作 LED，运行时关闭 SWD/JTAG；串口烧录不受影响。

串口下载时 BOOT0=1/3V3、BOOT1=0/GND；下载后 BOOT0 改回 0/GND，再复位运行。

## EXTI 配置与执行流程

代码集中在 `User/main.c`，便于对照课堂要求阅读：

1. `Hardware_Init()` 开启 GPIOA、GPIOB、AFIO 时钟，配置 LED、蜂鸣器输出以及四个按键上拉输入，释放调试引脚。
2. `exti_init()` 调用 `GPIO_EXTILineConfig()`，把 PA2、PA13、PA6、PA7 分别映射到 EXTI2、EXTI13、EXTI6、EXTI7。
3. EXTI 配置为中断模式、双边沿触发。下降沿记录按下变化，上升沿记录松开变化，消抖用最后一次边沿的时间判断。
4. NVIC 使用优先级分组 2，开启 EXTI2、EXTI15_10、EXTI9_5 三个入口；两个共享入口按各自线路分别检查。
5. ISR 通过 `EXTI_GetITStatus()` 判断来源，立即 `EXTI_ClearITPendingBit()` 清除硬件标志，记录时间和软件待处理标志；没有延时或流水灯循环。
6. `Buttons_Process()` 在主循环中确认最后一次边沿后已经过约 20 毫秒，再采样电平，稳定按下时执行一次对应动作。读取消费 ISR 共享数据时只短暂关闭中断，不会关闭 20 毫秒。
7. `Led_Update()` 根据时间戳切灯，主循环通过 `__WFI()` 等待下一次按键或系统时钟中断。

系统时钟仍为 72 MHz。`SysTick_Config(SystemCoreClock / 1000U)` 建立 1 毫秒周期中断，`SysTick_Handler()` 累加时间。**本实验不要调用旧的 `delay_ms()` / `delay_us()`，它们会重新配置同一个 SysTick，破坏周期计时。**

`SysTick_Handler()` 与 EXTI 入口均定义在 `main.c`；`stm32f10x_it.c` 中原有空 SysTick 实现已移除，避免重复定义。其余系统异常入口保留。

## 构建与验证

- Keil 工程：`Template.uvprojx`；烧录文件：`Obj/Template.hex`。
- 测试：`tests/exti_lab_test.c` 通过模拟 GPIO、EXTI、NVIC 和系统时钟，直接运行固件中的初始化、ISR 和处理逻辑。
- 覆盖：引脚映射、NVIC 配置、硬件标志清除、消抖、长按不重启、两种流水灯循环、蜂鸣器持续开启与关闭、共享中断同时触发和计时溢出。
- 实际按键接触、流水灯物理方向和声音仍需上板验证。
